Title: Password Reset

Problem:
A user cannot access an account because they forgot their password or their password has expired.

Possible Causes:
- Forgotten password
- Expired password
- Account lockout
- Incorrect username
- Authentication problem

Troubleshooting Steps:
1. Confirm that the correct username is being used.
2. Check whether the password has expired.
3. Use the organization's approved password reset process.
4. Complete identity verification if required.
5. Create a new password that meets the organization's password policy.
6. Try signing in again.
7. If the account is locked, wait for the required period or contact IT support according to organizational policy.

Security:
Never ask users to provide their current password or share passwords with support personnel.

Escalation:
If the password reset process fails or the account remains locked, escalate the issue to the appropriate IT administrator.
